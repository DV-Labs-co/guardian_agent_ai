# Feature Requests

## Critical

### Alexa+ MCP Starter Kit

Provide a complete Streamable HTTP MCP starter with `/mcp`, required headers, session behavior, tool examples, and local validation commands.

Why it matters: Alexa+ MCP is the centerpiece of the project, and teams need to spend time building differentiated agent behavior instead of reconstructing protocol boilerplate.

## Important

### Ring Webhook Payload Playground

Provide sample person, package, motion, and duplicate webhook payloads with valid signature examples.

Why it matters: webhook reliability and idempotency are hard to demonstrate without realistic payloads.

## Important

### AgentCore One-Command MCP Deploy

Provide a single documented path for deploying a sample MCP server to AgentCore Runtime and validating it with MCP Inspector.

Why it matters: AWS Builder projects need to prove AWS usage quickly and confidently.

## Nice-To-Have

### Fire TV Demo Dashboard Quickstart

Provide a simple way to run a local web dashboard on Fire TV or the Vega simulator.

Why it matters: Fire TV is a powerful visual surface for agent demos, but packaging can distract from the core product.
