# Friction Log: Fire TV

## Task

Display Guardian incident state on a Fire TV-style command center.

## Expected

Fire TV can show active incident state, recommended actions, and all-clear resolution.

## Actual

Local web dashboard implements the Fire TV command center view. Native Fire TV packaging is pending.

## Severity

Medium.

## Workaround

Use the browser dashboard in full-screen mode as the Fire TV visual layer for the hackathon demo.

## Suggestion

Provide a Fire TV web-app quickstart for hackathon teams using existing local web dashboards.

## Impact

This would make it easier to turn agent state into a compelling living-room demo surface.
